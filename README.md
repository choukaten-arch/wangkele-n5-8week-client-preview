# 八週 N5 陪跑－地端同版客戶驗收站

這是目前地端學員平台的 GitHub Pages 安全鏡像，用途是讓客戶直接驗收相同的品牌視覺、資訊架構、響應式排版與主要操作流程。

公開測試網址：<https://choukaten-arch.github.io/wangkele-n5-8week-client-preview/>

## 安全邊界

- 使用專案已核准的王可樂 Logo 與 N5 課程主視覺。
- 所有學員、作答、成績、登入紀錄及練習時數都是合成資料。
- 不含真實題文、正式答案、正式詳解、私有題庫或教材內頁。
- 不含學員個資、密碼、API 金鑰或其他秘密。
- API 行為由瀏覽器內的安全模擬層提供，只在本裝置保存測試狀態。
- 公開版不包含審題工作台、題庫匯出或學員帳號管理後台。
- 完整帳密、題庫、計分與資料保存需使用獨立 staging 環境。

## 預覽功能

- 與地端相同的首頁、每週測驗導覽與 N5 課程主視覺
- W01–W08、期末測驗與續答／交卷流程
- 25 課索引、各課句型預覽、三題合成課測與錯題詳解版面
- CAT 開始、作答、結果與個人化建議版面
- 學習 InBody、登入紀錄、累計練習時數、歷程、學習方式與聊天示意
- 登入、忘記密碼、一次性密碼與變更密碼流程

## 測試帳號

- 帳號：`demo@wangcola.test`（亦可輸入 `cola`）
- 密碼：`cola`
- 忘記密碼流程會顯示一次性測試密碼 `COLA-ONCE`

## 本機預覽

可直接開啟 `index.html`，或在本資料夾啟動任一靜態 HTTP server。範例：

```bash
python3 -m http.server 8080
```

然後開啟 `http://127.0.0.1:8080/`。

## GitHub Pages

部署時只需發布本資料夾內的白名單檔案。`preview-api.js` 會自動辨識 GitHub Pages 專案子路徑；`.nojekyll` 會防止 Jekyll 轉換。

此資料夾本身不建立 Git remote、不 commit，也不推送。

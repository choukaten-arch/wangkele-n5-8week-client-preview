# 八週 N5 陪跑－客戶靜態 UI 驗收版

這是可獨立部署到 GitHub Pages 的純靜態功能預覽。用途是讓客戶驗收資訊架構、視覺層級、響應式排版與基本交互。

## 安全邊界

- 全部畫面與數值都是合成資料。
- 不含品牌 Logo、教材圖片、真實題文、答案、詳解或題庫。
- 不含學員個資、密碼、API 金鑰或其他秘密。
- 不連線 API，不登入，不寫入或保存任何資料。
- 完整帳密、題庫、計分與資料保存需使用獨立 staging 環境。

## 預覽功能

- 八週進度與期末綜合測驗
- 25 課索引與合成句型標籤展開
- 合成週測作答流程
- CAT 合成診斷狀態切換
- 學習 InBody 合成數據
- 管理後台唯讀示意

## 本機預覽

可直接開啟 `index.html`，或在本資料夾啟動任一靜態 HTTP server。範例：

```bash
python3 -m http.server 8080
```

然後開啟 `http://127.0.0.1:8080/`。

## GitHub Pages

部署時只需發布本資料夾內的檔案。`index.html` 使用相對路徑，可在專案頁面或組織頁面下運作。`.nojekyll` 會防止 Jekyll 轉換。

此資料夾本身不建立 Git remote、不 commit，也不推送。
